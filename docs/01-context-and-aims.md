# Context and Project Aims

The aim of this project was to design a playable physical-modelling
audio plugin for composers, producers, sound designers, and students.

The synthesiser creates plucked-string textures without relying on
recorded sample libraries. It is not intended to exactly emulate a
particular guitar or harp, but instead functions as a flexible synthetic
instrument with direct control over the behaviour of a virtual string.

The plugin was designed for use in a DAW and can be controlled through
MIDI, played polyphonically, automated, recorded, and saved as presets.
